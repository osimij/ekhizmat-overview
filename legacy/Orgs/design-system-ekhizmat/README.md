# Дизайн-система eKhizmat — АРМ оператора ЦОН

Самодостаточный комплект дизайн-системы: токены, компоненты, иконки и живая
витрина. Скопирован из `../ekhizmat-arm`. Приложение продолжает работать со
своими файлами — этот каталог их **не заменяет**, а собирает систему в одном месте
для просмотра, ревью и передачи дизайнерам/разработчикам.

## Как открыть витрину

Нужен HTTP-сервер (не `file://` — иначе спрайт иконок через `<use href>` не подгрузится):

```bash
cd design-system-ekhizmat
python3 -m http.server 8413
```

Открыть: <http://localhost:8413/styleguide.html>

Есть тумблер светлой/тёмной темы в правом верхнем углу.

## Что внутри

```
design-system-ekhizmat/
├── styleguide.html      ← ЖИВАЯ ВИТРИНА. Открывать это. Все компоненты вживую.
├── css/
│   ├── tokens.css       ← ЯДРО. Единственный источник цвета/отступов/радиусов.
│   │                       Значения сняты с Figma (light = node 8-2, dark = 10-81).
│   │                       Правило: в компонентах ни одного сырого hex.
│   ├── base.css         ← reset + типографика (шрифт Google Sans → Inter → system)
│   ├── components.css    ← библиотека компонентов (кнопки, поля, пилюли, модалы, …)
│   └── screens.css      ← прикладной слой: раскладки экранов АРМ (не примитивы системы,
│                           витрина его не использует; включён для полноты)
├── assets/
│   ├── icons.svg        ← спрайт из 70 иконок. Использование:
│   │                       <svg class="icon"><use href="assets/icons.svg#i-qr"/></svg>
│   └── qr-placeholder.svg
└── tools/               ← сопровождение дизайн-системы
    ├── check-contrast.py     # проверка контраста прямо из tokens.css (§4.4 / §9)
    ├── fix-contrast.py       # авто-подбор значений под контраст
    ├── build-sprite.py       # сборка assets/icons.svg
    ├── build-qr-placeholder.py
    └── icons-frame.svg       # исходный фрейм иконок
```

## Слои и порядок подключения

Витрина и приложение подключают CSS строго в этом порядке:

```html
<link rel="stylesheet" href="css/tokens.css">      <!-- 1. переменные -->
<link rel="stylesheet" href="css/base.css">        <!-- 2. reset + типографика -->
<link rel="stylesheet" href="css/components.css">  <!-- 3. компоненты -->
<!-- css/screens.css — только в приложении, для экранов -->
```

## Темизация

Светлая — по умолчанию (`:root`). Тёмная — через атрибут на корне:

```html
<html data-theme="dark">
```

Все компоненты читают только CSS-переменные, поэтому тема переключается целиком
одним атрибутом, без правок в компонентах.

## Проверка контраста

```bash
python3 tools/check-contrast.py      # считает контраст из css/tokens.css
```
